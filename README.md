# Presley Mayer Portfolio

Multi-page portfolio built with HTML, CSS, JavaScript, and Bootstrap 5.

## Run it
Open the folder in VS Code, right-click `index.html`, and choose **Open with Live Server**.
(The Projects page uses `fetch()`, so it won't load if you double-click the file.)

## Features
- Responsive Bootstrap navbar, grid, cards, badges, accordion, and modal
- Projects loaded from `data/projects.json` with `fetch()`
- Category filter buttons and keyword search
- Project details modal
- Dark/light mode toggle
